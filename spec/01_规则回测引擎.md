> 文档状态：落地级（待开发）

---

## 1. 目标与范围

### 1.1 目标
提供**无未来函数**的A股规则策略回测能力：用户用结构化参数（指标信号 + 比较 + 阈值）定义策略，引擎在严格撮合与成本模型下给出可审计的绩效。

### 1.2 In Scope
- 撮合引擎（T+1 成交、防未来函数）。
- 成本模型（印花税/佣金/过户费）。
- 绩效指标（收益/夏普/回撤/胜率/基准对比）。
- 结构化信号规则 DSL（指标 + 比较算子 + 阈值）。
- 参数校验与异常降级。

### 1.3 Out of Scope
- 自然语言策略（见 Phase 3）。
- 实盘下单、模拟盘资金账户（不做）。
- 机器学习/遗传优化（不做）。

## 3. 功能描述

### 3.1 信号规则 DSL
- 原子信号：`{indicator} {op} {threshold}`，如 `ma5 > ma20`、`rsi14 < 30`、`macd_hist > 0`。
- 组合：支持 `AND`/`OR` 连接多个原子（最多 4 个）。
- 指标来源于 `indicators/registry` 的 compute 结果列。

### 3.2 撮合引擎（关键：防未来函数）
- 信号在 **T 日收盘**基于当日及之前数据计算。
- 成交在 **T+1 日**（开盘价或收盘价，参数可选）执行，禁止用 T 日及之后信息。
- 持仓单位：整百股（A股手数规则），现金不足则按可用资金上限买入。
- 平仓：信号转空或到期（可选持有天数上限）触发卖出。

### 3.3 成本模型（A股真实）
- 印花税：卖出 0.05%（单边）。
- 佣金：万 2.5，单笔最低 5 元。
- 过户费：成交金额 0.001%（双边）。
- 滑点：可选，默认 0（可在参数设 0–0.5%）。

### 3.4 绩效指标
- 累计收益率、年化收益率、最大回撤、夏普比率（无风险利率取 10 年期国债近似 2.5%）。
- 胜率（盈利交易/总交易）、基准对比（沪深300 同期收益 + 超额收益）。
- 输出：权益曲线（时间序列）、交易明细（买卖日期/价/量/盈亏）、绩效 JSON。

---

## 4. 输入 / 输出

### 4.1 输入（JSON）
```
{
  "stock_code": "000001",
  "start": "20230101", "end": "20231231",
  "initial_cash": 100000,
  "signal": "ma5 > ma20 AND macd_hist > 0",
  "fill_price": "close",   // open | close
  "cost": { "commission": 0.00025, "min_commission": 5, "stamp": 0.0005, "transfer": 0.00001, "slippage": 0 },
  "benchmark": "000300.SH"
}
```

### 4.2 输出
- `trades`: 成交明细数组。
- `equity_curve`: [{date, value, benchmark_value}]。
- `metrics`: {total_return, annual_return, max_drawdown, sharpe, win_rate, excess_return}。
- `code_ref`: 实际执行的撮合版本/参数摘要（可审计）。

## 5. 业务规则与异常流程
- **日期颠倒 / 空区间**：返回 400，文案「回测区间无效，请检查起止日期」。
- **初始资金 <= 0**：返回 400，文案「初始资金需大于 0」。
- **信号解析失败**（未知指标/算子）：返回 400，列出可用指标与算子。
- **数据缺失**（区间内某日无行情）：跳过该日并 `data_flag` 提示；缺失 > 20% 区间则中止并提示换区间。
- **计算溢出**（极端值）：捕获异常，返回 500 + 降级文案「回测计算异常，请缩小区间或调整参数」。

---

## 6. UI 交互规则
- 回测表单：股票代码、日期区间（日历控件）、指标信号可视化拼接器（下拉选指标+算子+阈值，自动拼 DSL）。
- 结果页：权益曲线（含基准叠加）、K线+买卖点标记、交易明细表（分页，每页 20 条，可导出 CSV）。
- 加载态：回测中显示进度/骨架屏；空状态：无交易时提示「该策略在区间内未触发交易」。
- 图表颜色沿用 v1.3 配色规范（买入点绿、卖出点红）。

---

## 7. 验收标准
- AC1.1：给定 `ma5>ma20` 策略在已知区间回测，与手算样本（前 3 笔交易）一致，误差 < 佣金精度。
- AC1.2：构造「用 T 日收盘价买入 T 日信号」的作弊策略，引擎拒绝或在测试中证明 T+1 成交（防未来函数单测通过）。
- AC1.3：成本模型单测——10 万元卖出，印花税+佣金+过户费合计与手工一致。
- AC1.4：非法参数（日期颠倒/资金<=0/未知指标）均返回结构化错误，前端准确提示。
- AC1.5：权益曲线含基准叠加，绩效 JSON 含全部规定字段且类型为数值。

---

## 8. 风险
- 未来函数风险（最高）：应对——撮合单测 + 代码评审强制 T+1。
- Tushare 行情缺口：应对——缺失率阈值 + 区间提示。
- 绩效口径歧义：应对——指标公式在 spec/代码注释中固化，UI 展示口径说明。
