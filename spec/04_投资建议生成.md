# Phase 4 · 模块4 投资建议生成 Spec

> 文档状态：落地级（待开发）
> 关联：主文档 `SPEC.md`、Phase 1 回测引擎、Phase 2 Agent 编排、`ai/analyzers/*`
> 前置依赖：Phase 1（回测结果）、已落地分析器（估值/财务健康/风险/动量/评分）、Phase 2（`suggest_investment` 工具）

---

## 1. 目标与范围

### 1.1 目标
基于多维度分析器（估值、财务健康、风险、动量、评分）与可选回测结果，产出**结构化的 AI 投研观点（仅供参考）**。这是 spec v3.1 新增允许项：平台可生成「观点」，但**严禁荐股、严禁收益承诺、严禁保本表述**。

### 1.2 In Scope
- 输入聚合：分析器输出 +（可选）回测绩效 + 行情快照。
- 观点生成：方向（看多/中性/看空）+ 多因子理由 + 主要风险 + 数据来源。
- 合规措辞强制校验。
- 接入 Phase 2 `suggest_investment` 工具，可被 Agent 在研究闭环中调用。

### 1.3 Out of Scope
- 任何买卖指令、目标价、仓位建议、保本/收益承诺。
- 实盘/模拟盘执行。

## 3. 功能描述与业务规则

### 3.1 输入
```
{
  "stock_code": "000001",
  "include_backtest": true,        // 可选，附 Phase1 绩效
  "context": "用户研究问题摘要"     // 可选
}
```

### 3.2 输出结构
```
{
  "stance": "看多 | 中性 | 看空",
  "confidence": "高 | 中 | 低",
  "reasons": [ { "factor": "估值", "finding": "...", "weight": 0.3 }, ... ],
  "risks": [ "短期流动性风险...", ... ],
  "data_sources": [ "财务三表 2023Q3", "回测区间 2023 收益+x%" ],
  "disclaimer": true
}
```

### 3.3 生成规则
- 方向由因子加权得出（估值低估+财务健康+动量向上→偏多；反之偏空），但 LLM 仅负责**自然语言组织**，核心判断来自分析器数值，避免纯幻觉。
- 理由必须**可追溯到具体因子与数据**（`data_sources` 回链）。
- 置信度由因子分歧度决定（因子一致→高，分歧大→低）。

### 3.4 合规强校验（关键，§6.5）
- **禁止词库**实时扫描输出：买入/卖出/建仓/清仓/目标价/看涨至/必涨/稳赚/保本/无风险/收益保证/推荐购买。
- 命中即拦截并重写，或返回错误「内容触发合规拦截，已调整」。
- 输出顶部/底部强制免责：「本内容为 AI 基于公开数据的投研观点，仅供参考，不构成任何投资建议，不承诺收益，投资有风险。」
- 所有建议页面 `disclaimer=true`。

---

## 4. 异常流程
- 分析器数据缺失：跳过该因子并在 `reasons` 标注「数据不足」，不臆造。
- LLM 超时：返回缓存的分析器摘要（无自然语言润色）+ 免责。
- 合规拦截：重写后仍命中→返回「暂无法生成该观点，请联系人工复核」。

---

## 5. UI 交互规则
- 「AI 观点」卡片：方向徽标（看多绿/中性黄/看空红，沿用 v1.3 配色）、置信度、因子理由列表、风险列表、来源折叠。
- 强制免责条常驻。
- 加载态：因子聚合动画；空状态：数据不足提示。

---

## 6. 验收标准
- AC4.1：输入某股，返回的 `stance` 与（估值低估+财务健康+动量向上）因子方向一致，且每条 reason 有 `data_sources` 回链。
- AC4.2：在生成结果中人为注入「建议买入」→ 合规扫描拦截，输出不含该词且 `disclaimer=true`。
- AC4.3：分析器数据缺失时，`reasons` 含「数据不足」标注，无幻觉数值。
- AC4.4：经 Phase 2 Agent 调用 `suggest_investment`，能在研究闭环中返回结构化观点并携带免责。

---

## 7. 风险
- 合规表述漂移（最高）：应对——禁止词库 + 输出前 LLM 自检 + 人工抽检。
- 幻觉因子：应对——理由必须绑定分析器数值，禁无源陈述。
- 用户误读为荐股：应对——页面强免责 + 措辞规范培训（文档化）。
