# Phase 5 · 模块6 报告生成增强 Spec

> 文档状态：落地级（待开发）
> 关联：主文档 `SPEC.md`、Phase 4 投资建议、模块2 RAG、模块5 可视化
> 前置依赖：Phase 4（AI 观点）、已落地导出能力、`ai/analyzers/*`、RAG 来源

---

## 1. 目标与范围

### 1.1 目标
将投研过程沉淀为**可发布的自媒体投研文稿与复盘报告**：结构化模板、融合 AI 观点（Phase 4）、数据来源回链、强制免责页脚。面向财经自媒体创作者的核心产出。

### 1.2 In Scope
- 结构化投研文稿模板（含 AI 观点章节、数据来源章节）。
- 复盘 PDF（融合 K线/指标图 + 关键指标 + AI 观点）。
- 导出格式：Markdown（自媒体可直接发）、PDF（复盘存档）。
- 合规页脚：每份报告强制免责声明。

### 1.3 Out of Scope
- 自动发布到第三方平台（不做，仅导出本地）。
- 实盘相关结论。

---

## 2. 依赖与前置
- Phase 4 `suggest_investment` 输出。
- 模块5 图表（K线/指标，v1.3 配色）。
- 模块2 RAG 来源（财报/公告切片）。

---

## 3. 功能描述与业务规则

### 3.1 文稿结构（Markdown）
```
# {股票} 投研文稿
## 一、行情与技术面（附 K线+指标图）
## 二、基本面与财务健康
## 三、AI 投研观点（Phase4：方向/置信/理由/风险）  ← 强制免责条
## 四、数据来源
  - 财务三表 20xxQx（db）
  - 公告/研报切片（RAG: doc_id）
## 免责声明（页脚，不可移除）
```

### 3.2 复盘 PDF
- 封面：股票/区间/生成时间。
- 正文：嵌入行情图（base64 或引用）、关键指标表、AI 观点卡。
- 页脚：免责声明每页重复。

### 3.3 合规
- 文稿与 PDF 均**不可关闭**免责声明；模板内固定占位，导出时强制注入。
- 若含 Phase 4 观点，须保留原始 `disclaimer=true` 标记。

---

## 4. 输入 / 输出
- 输入：`{ stock_code, date_range, include_ai_view: true, format: "md"|"pdf" }`。
- 输出：文件流（`.md` / `.pdf`），含上述结构与免责。

---

## 5. UI 交互规则
- 报告生成入口：个股页「生成投研文稿 / 复盘 PDF」按钮。
- 模板选择：默认模板 + 可选「精简版 / 完整版」。
- 加载态：渲染进度；空状态：数据不足提示先补数据。
- 导出后提供下载链接 + 「复制到剪贴板」（Markdown）。

---

## 6. 验收标准
- AC5.1：生成 Markdown 含全部规定章节，且免责声明存在于文末。
- AC5.2：生成 PDF 每页页脚含免责声明，且嵌入的 K线图与页面渲染一致（v1.3 配色）。
- AC5.3：包含 Phase 4 AI 观点时，文稿中观点章节标注「仅供参考」且来源可回链。
- AC5.4：尝试在模板中删除免责占位 → 导出仍自动注入免责（不可移除）。

---

## 7. 风险
- 图表嵌入失真：应对——复用前端渲染一致的颜色/类型约定。
- 自媒体误用为荐股：应对——强免责 + 文稿内提示「非投资建议」。
- 长文档性能：应对——分页渲染 + 图片压缩。
