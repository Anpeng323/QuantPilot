## 编写约定
- 所有 AI 输出必须附带免责声明（见 `00_产品规格总览.md` §6.5）。
- 每个模块文档需包含：功能描述、输入输出、业务规则、UI 交互规则、正向/异常流程、验收标准。
- 修订统一在文首「修订记录」登记，并与 `git tag` 基线对齐。
